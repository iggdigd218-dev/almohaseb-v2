## مرشحات مكتشفة بقراءة المصدر — لا تعتبر مختبرة حتى إرفاق نتيجة إعادة إنتاج
1. **SAVE-RACE**: `_saving` يُضبط بعد await 50ms؛ ضغطتان ضمن الفاصل تستطيعان عبور الحارس. نحتاج اختبار Widget بضغطتين قبل pump.
2. **SAVE-TIMEOUT**: Future.timeout لا يلغي الكتابة؛ إعادة تمكين الزر بعد 10s قد تسمح بتكرار عملية لا تزال قيد التنفيذ.
3. **SAVE-ACTIVITY**: سجل النشاط مكتوب بعد commit العملية؛ فشل السجل قد يعرض فشلًا رغم حفظ المال. نحتاج SQLite trigger يرفض activity.
4. **ACCOUNT-SIGN**: نموذج تعديل حساب يعرض abs(openingBalance) ثم يحفظه مباشرة؛ قد يحوّل رصيدًا سالبًا إلى موجب دون تغيير المستخدم.
5. **SYNC-RETRY**: عداد attempts يزيد عند markSyncing ثم عند markFailed؛ والصف failed النهائي يُلتقط مجددًا بلا حد.
6. **SYNC-LIFECYCLE**: مؤقت 6h لا يُحتفظ به، stop لا يلغي immediate/callback/LAN. نحتاج اختبار lifecycle.
7. **SYNC-LAN**: المسجل يضيف هدف cloud فقط، ولا يظهر توليد هدف lan:broadcast بعد حفظ العملية.
8. **SYNC-REMOTE**: تطبيق settings يفترض عمود id غير موجود، ودمج integer ids من جهازين قد يفقد البيانات. اختبارات بين قواعد مستقلة مطلوبة.
9. **PERM-FAILOPEN**: can/_ensureCan وموفرو الواجهة يسمحون عند timeout/exception. نحتاج اختبار fault injection.
10. **FORMAT**: parseAmount يتجاهل الفاصلة العشرية الثانية بدل رفض الإدخال؛ مثال 1.2.3.
11. **SHARE-RESULT**: sendNow يعيد void حتى إن لم يُرسل شيء؛ واجهة الحفظ قد تدعي إرسال السند عند channel=none.
12. **UPDATER**: توجد آلية نشر GitHub فقط؛ لا يظهر عميل تحديث مركزي داخل التطبيق. لا يُصنف PASS.

> لا تعادل مراجعة المصدر اختبارًا بصريًا أو تشغيلًا على Android. ولا تعادل معاينة HTML القديمة تشغيل Flutter. سيحتوي التقرير النهائي على PASS / FAIL / BLOCKED مع نوع الدليل.

## إعادة الإنتاج المثبتة (قبل أي إصلاح وظيفي جديد)
- `ui-before.log`: 13 اختبار Widget؛ 7 PASS / 6 FAIL. ضبط `_saving` المتأخر سمح باستدعاء saveTx مرتين. مهلة 10s أعادت زر إعادة المحاولة والـFuture لا يزال معلقًا. channel=none عُرض معه «إرسال السند». تعديل -500 حفظ +500. overflow عند 320 و360 في اختبار Widget.
- `data-sync-before.log`: 19 اختبار SQLite/queue؛ 7 PASS / 12 FAIL. activity trigger رفض الكتابة بعد حفظ العملية بالفعل. allBalances أعاد 600 بدل100 بعد الحذف. ثمانية حفظات متوازية كلها بالمرجع1. تحويل لنفس الحساب قُبل. خطأ الصلاحية سمح. 1.2.3 صار1.23. attempts=2 لمحاولة واحدة. failed أعيد التقاطه. لم ينشأ هدفLAN. إعداد وارد فشل بسبب `no such column: id`.
- `runtime-build-verbose.log`: بناء Linux اختباري للكود الحالي PASS (exit0)، بعد إصلاح الكاش وتوفير swap للبناء.
- `runtime-dashboard.png`: أول مشاهدة فعلية للوحة التحكم باللغة العربية. المعاينة التفاعلية تعمل عبر 6080، ولا تحمل بيانات مستخدم حقيقية.
- `lifecycle-before.log`: عند stop بقي مؤقتان نشطان (200ms و6h)، اختبار FAIL مثبت.
- `rtl-before-details.log`: منشئ overflow هو `Row ← Padding ← SectionTitle`؛ عنوان القسم غير مرن. المعاينة الضيقة الحقيقية ستُقارن كذلك، واختبارات Widget لا تمثل حروف/محرك Android بالكامل.

## اختبار شبكة LAN حقيقية (loopback)
- عُطّل HttpOverrides الاختباري في ملف اختبار LAN فقط حتى لا تُحتسب استجابةFlutterالوهمية400 كشبكة حقيقية.
- `lan-sql-diagnosis.log`: سبب500 الفعلي هو استخدام `""` كنصSQL؛ SQLiteFFI الحالي يعامله اسم عمود. أُصلحت الثوابت لتستخدم single quotes القياسية، دون إضعاف المصادقة.
- `lan-auth-before.log` بعد تصحيحSQL: 3PASS/2FAIL. الاتصال المباشر بسر المرسل نجح، لكن `LanSyncService.push` أرسل سر المستقبل، فرفضه /ops (403). الإصلاح يطابق هوية المرسل بسرّه المحلي؛ لا يتجاوز فحص اعتماد الجهاز.
- `lan-security-before.log`: بعد إصلاح هوية السر، 5PASS/4FAIL. المشاهد المقترن استطاع الكتابة عبرHTTP رغم دوره، ولقطة البيانات كشفت أسرار أجهزة أخرى وPIN/password. والبث دون أي جهاز عُدّ نجاحًا. هذه حالات اختبار بأسرار اصطناعية فقط.
- `release-blockers-before.log`: أربعة موانع إضافية مثبتة: اصطدام معرّفات حسابين مستقلين، غياب سطور الفاتورة من المزامنة التزايدية، POS نقدي بدون عميل يرسلFK=0، ومؤشرCloud بالمللي ثانية بينما timestampالمخزنISO. لا تُخفي مجموعة الاختبارات هذه الإخفاقات.
- `lan-after.log` بيّن أن تعدادNetworkInterface في بيئة الاختبار خالٍ؛ IP المُعلن فارغ فرفض الاقتران. اعتمد الخادم عنوانsocket الفعلي بدل عنوان العميل المعلن (أدق أيضًا ضد إعلان عنوان طرف ثالث)، وأضيفdeviceId المفقود في جوابالاقتران. تحفظ اللقطة المنقحة أسرار الاقتران المعروفة محليًا فقط، ولا توزع أسرار بقية الأجهزة.
- تعديلاتAndroid: إزالة READ_MEDIA_IMAGES/WRITE_EXTERNAL_STORAGE غير المطلوبة لمسارsystem picker/private storage، camera featureاختيارية، وقصرFileProvider علىcache/shared الذي تنسخ MainActivity المرفقات إليه. تحققXMLPASS؛ اختبارالأذوناتعلىAndroidومراجعةmanifestالمُدمج مازالاBLOCKED.
